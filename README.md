# Ecommerce Sales Performance Dashboard | Power BI

An interactive Power BI dashboard designed to analyze e-commerce sales performance, profitability, customer contributions, product categories, and payment preferences through meaningful data visualizations.

## 📌 Project Overview

The Ecommerce Sales Performance Dashboard is a data analytics project built using Microsoft Power BI to explore e-commerce sales data and present important business metrics in a clear, interactive, and visually appealing format.

The dashboard provides an overview of total sales, quantity sold, profit, and average order value (AOV). It also includes detailed visualizations for monthly profit trends, state-wise sales, customer-wise sales, payment mode distribution, category-wise quantity, and sub-category profitability.

The main objective of this project is to understand how sales data can be transformed into meaningful business insights using interactive dashboards and data visualization techniques.

## 🎯 Project Objectives

- Analyze overall e-commerce sales and profitability.
- Monitor key business performance indicators through KPI cards.
- Understand monthly profit trends and variations.
- Compare sales performance across states and customers.
- Analyze customer payment preferences.
- Explore product category and sub-category performance.
- Build an interactive dashboard that presents business data in an easy-to-understand format.

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)
Created KPI cards to display four important business metrics:
- Total Sales Amount
- Total Quantity Sold
- Total Profit
- Average Order Value (AOV)

### 2. Monthly Profit Analysis
A monthly profit chart that helps compare performance across months and identify positive and negative profit trends.

### 3. State-wise Sales Analysis
A horizontal bar chart to compare sales amounts across different states and understand their contribution to overall sales.

### 4. Customer-wise Sales Analysis
A column chart to compare sales contributions from individual customers and identify customers with higher sales values.

### 5. Payment Mode Analysis
A doughnut chart showing the distribution of orders across payment methods, including COD, UPI, debit cards, and credit cards.

### 6. Category-wise Quantity Analysis
A doughnut chart representing the quantity distribution across Clothing, Electronics, and Furniture.

### 7. Sub-category Profit Analysis
A horizontal bar chart comparing profit across product sub-categories to help understand their relative performance.

### 8. Interactive Quarterly Slicer
A quarter-based slicer that allows users to explore data across different quarters and observe changes in sales and profitability.

### 9. State Dropdown Filter
A dropdown filter that helps users focus on selected states and interact with the dashboard more effectively.
